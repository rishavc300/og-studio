# OG Studio privacy policy

OG Studio does not collect, store on any server, sell or send any personal data. It has no servers and contains no analytics or tracking.

It runs only on studio.youtube.com. It changes how Studio's own pages load in your browser. When it needs channel information, it asks Studio directly, the same way the Studio page does, using the session you are already signed in with. To do that it reads your Studio session cookie inside the page. The cookie and your channel data never go anywhere except Studio.

It saves three small things in your browser:

- the last date range you picked
- whether your channel has revenue, so the Revenue tab doesn't flash on load
- a short-lived note, if the classic page failed to load, to use the backup page for an hour

Questions: open an issue at https://github.com/rishavc300/og-studio/issues
